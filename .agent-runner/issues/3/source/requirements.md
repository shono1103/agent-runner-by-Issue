## 要件定義

### 背景

#2 で `type:bug` ラベルの付いたissue (バグ報告) を識別できるようになる前提で、そのissueに対して原因調査を自動実行できるようにする。

### 要件

1. `type:bug` ラベルが付いたissueに対して、対象リポジトリのコードを読ませたうえでclaude cliに調査を実行させられること
2. 調査への入力は、issue本文 (バグ報告テンプレートの「再現手順」「期待する動作」「実際の動作」) とすること
3. 調査結果には、原因と推測される箇所 (ファイルパス・行または関数名) と、そう判断した根拠を含めること。コード上の根拠が見つからない場合は「特定できなかった」旨と、確認した範囲を明示すること
4. 調査結果はissueへの新規コメントとして投稿されること
5. 同じissueに対して再実行した場合、コメントが増殖せず、既存の調査結果コメントが更新されること
6. 調査はコードの読み取りのみを行い、対象リポジトリに変更を加えないこと (commit・push は行わない)
7. userscript側に、バグ報告issueでのみ表示される「調査を実行」ボタンを追加すること

### 非機能要件

- 既存の「タスク」用ジョブ (要件定義等の変換、PR作成) の挙動やAPIには影響を与えないこと
- 調査ジョブの実行中は対象issueに対する他ジョブの同時実行をブロックすること (既存の `convert` ジョブと同水準のissue単位ロックで足りる。git push を伴わないためリポジトリ単位ロックは不要)
